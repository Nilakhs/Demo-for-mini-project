          Why consumer_compile waits
          consumer.c has #include "generated_config.h". The GCC preprocessor must open this file before compilation begins. If it does not exist, the compiler fails immediately with a fatal error — not a race condition, a hard dependency.
        

        

          Why independents run in parallel
          independent1/2/3 share no output files and no input dependencies between them. The scheduler finds them all READY at the same time and dispatches three threads simultaneously. Real subprocess concurrency — check the log timestamps.
        

        

          What the scheduler algorithm does
          Every 150 ms, the scheduler scans all QUEUED tasks. If all dependencies are DONE → dispatch immediately. If any dependency is FAILED/BLOCKED → mark BLOCKED. This is topological sort + concurrent frontier dispatch.
        

        

          Real-world analogy (SQLite)
          lemon.c compiles to lemon → lemon parse.y produces parse.h → tokenize.c and expr.c #include "parse.h". Exactly the same pattern. Production scale.
